# stellar-zkstream Frontend

React UI for creating and managing privacy-preserving payment streams.

## Current status — what's real vs. not

**Wired to real deployed testnet contracts, not mocked.** `src/soroban.ts` uses
`@stellar/stellar-sdk`'s `contract.Client` to talk directly to the real, deployed
`stream` and `zk_verifier` contracts (see `../deployments/testnet.json`). Two things are
genuinely real and independently verifiable in the browser right now:

- **"Verify Real Proof On-Chain"** — needs no wallet. Simulates a real call to the real
  deployed range-proof verifier with a real Groth16 proof (generated by the actual
  trusted-setup pipeline in `../circuits/`) and shows the real `true`/`false` result.
- **"Create Real Stream"** — needs a connected Freighter wallet. Builds, simulates, and
  (once you sign in Freighter) submits a genuine `create_stream` transaction to testnet.

**What's still limited, and honestly so:** creating a stream only works for one fixed
amount (0.5 XLM), because it submits the one precomputed real proof this repo has
generated so far (see `circuits/build/range_proof/`). Proving an arbitrary amount would
need in-browser proof generation — bundling the circuit's WASM witness calculator and a
Groth16 prover (snarkjs) to run client-side — which is real future work, not built yet.
Withdrawal (the nullifier-proof path) isn't wired into this UI at all yet.

## Prerequisites to actually use it

- The [Freighter](https://freighter.app) browser extension, set to **Testnet**.
- A funded testnet account (Freighter can request testnet XLM from friendbot itself).

## Running it

```bash
npm install
npm run dev
```
